# Personal AI OS Core

这是一个面向长期运行个人 AI Agent 的权威感知控制面核心。

仓库保留五项可运行机制：从证据编译当前事实、按明确边界路由任务、隔离候选与已接受状态、生成紧凑恢复快照、校验冻结资产是否发生漂移。

## 运行

需要 Python 3.10 或更高版本，无运行时依赖。

```bash
make demo
make test
```

演示只使用合成数据，并输出机器可读结果：

```json
{"checks":["asset_freeze","candidate_promotion","domain_route","truth_compile"],"data_source":"synthetic","status":"SAFE"}
```

需要在仓库外调用命令时，可安装本地包：

```bash
python3 -m pip install --no-deps -e .
personal-ai-os demo
```

## 核心合同

| 模块 | 规则 |
|---|---|
| 事实编译 | 已接受证据可以形成当前事实；看板和快照只做视图；同级证据冲突时返回 `UNKNOWN`。 |
| 领域路由 | 每条路由声明领域、执行器、允许输入和允许输出；缺少路由或越界请求会停止。 |
| 候选晋升 | 候选同时具备证据和匹配的人类最终决定后，才能进入已接受状态。 |
| 连续性快照 | 恢复信息只保留权威、当前状态和下一动作，并生成确定性摘要。 |
| 资产冻结 | 清单记录文件摘要；文件缺失或内容变化都会阻断校验。 |

## 数据边界

仓库只包含合成示例，不包含凭证、个人路径、私人记忆、业务记录、科研结果、运行日志和历史回执。模型供应商、浏览器、云存储与消息系统集成不属于这个核心仓库。
