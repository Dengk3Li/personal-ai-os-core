# Personal AI OS v0.19 开发任务书

状态：`CANDIDATE / 公开 feature branch`

## 本轮目标

为长期任务提供一份可跨执行器读取的、有界恢复胶囊。胶囊只描述恢复所需的运行引用，不复制任务正文、模型输出、本地路径或凭据。

## 已交付

- 新增 `personal-ai-os.continuity/v2` 纯函数合同。
- 胶囊固定包含任务状态、依赖状态、最新运行引用、最新决定引用、有界阶段产物引用和下一步动作。
- 任务、运行、决定和产物使用不含路径与凭据的 opaque reference；依赖和产物引用数量有上限，下一步动作有长度上限。
- 复用现有 `continuity` 摘要与 RuntimeStore 的事实，不新增表、后台 daemon、恢复 Worker 或隐式重试。
- 每个 runtime acceptance snapshot 附带胶囊；`public-safe` 在现有匿名化投影后构建，保持公开标识边界。
- 胶囊只读、带稳定摘要，可被后续执行器读取；读取不会 claim task、启动模型、接受验收或提升记忆候选。

## 设计参考

Prime Agent 的持久续推、LangGraph 的 checkpoint/interrupt、OpenHands 的事件与执行服务分层、Letta 的持久上下文用于校验边界。项目只吸收“持久状态、恢复边界、执行与投影分离”的通用机制，未复制其实现或运行时。

## 验收边界

- 任意输入中的任务正文、运行输出、决定问题、本地路径和凭据不会进入胶囊。
- 公开安全投影不会通过胶囊重新暴露真实任务、运行、决定或产物标识。
- 缺少有效任务引用或超过有界集合限制时，合同返回明确错误；不会生成不完整的恢复记录。
- 运行连续性仍是投影能力，不代表外部运行已自动恢复，也不代表任务已被人工验收。

## 未交付边界

- 没有后台持续运行、自动恢复、取消或跨机器传输协议。
- 没有把胶囊正文写入 memory store，也不会把候选经验自动转为批准记忆。
- 没有修改公开 `main`；真实研究报告的终态和人工验收仍是后续封包门槛。
