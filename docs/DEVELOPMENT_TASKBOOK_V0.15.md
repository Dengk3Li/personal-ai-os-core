# Personal AI OS v0.15 开发任务书

状态：`CANDIDATE / 尚未封包`

## 本轮目标

把模型与路由配置从工作页面移入右上角设置，并让私人本地运行库可以从浏览器真实绑定 Codex 或兼容 API。绑定完成后，当前工作线沿既有 Broker、Human Gate、预算和恢复边界执行有界自动推进。

## 已交付

- 私人本地模式新增 `/api/settings/execution`，只接受同源 loopback JSON 请求。
- Codex 自动配置读取本机 `codex` 可执行文件、登录状态和默认模型，通过 app-server 完成真实 thread/turn。
- 兼容 API 密钥只保存在当前服务进程，不进入运行投影、SQLite、事件或错误回包。
- 任务路由在整包校验通过后原子替换；无效 Adapter、模型、能力或上下文上限不会改变旧设置。
- 设置页提供 Codex 自动绑定、兼容 API 绑定和路由编辑；工作进度页只保留开始、继续、验收与裁决。
- 私人本地模式持久保存 Codex 项目绑定、默认模型和任务路由；服务重启后重新检查适配器可用性。兼容 API 的密钥与端点仍只保留在进程内。
- 同一 Broker 持有的活跃运行显示为“进行中”；其他实例或重启后读到的遗留运行进入恢复确认。
- 运行中的模型任务不能被页面提前提交验收。
- 工作线可在设置中绑定已登记的 Codex 项目；任务先进入持久派发队列，再由桌面总管使用真实 `projectId` 创建项目内任务并回写结果。
- 项目 worker 向桌面桥接层显式传递 `project_id`、`project_path`、`environment`、`model` 和 `prompt`，并按 `LongTask · <task_id> · <dispatch_id后8位>` 生成任务标题；缺少项目 ID、路径或合法环境时在创建前收口，不创建无项目归属的任务。
- 线程绑定必须同时取得允许的项目归属来源和路径、环境、项目 ID 一致性验证；终态回写必须提供已验证的 terminal receipt、非空最终输出，并确认没有待用户输入或 Human Gate。
- worker 只把执行结果送到 `REVIEW`，不自动验收、不自动批准 Human Gate、不自动合并或推送 `main`。
- 项目派发使用 15 分钟认领租约；失联后可重新接管，任务收口只能成功一次。
- 任务详情补充真实验收回执：展示已登记产物的摘要、产出时间和私有本地模式下的有界预览；公开投影只保留通用登记状态，不暴露正文。
- 时间线使用运行事件的完整发生时间与 `run_id`；侧栏同步展示任务前因、当前结果和后果/下一步，依赖关系直接来自工作流图。
- 公开核心新增只读 `personal-ai-os.acceptance/v1` 投影：统一返回任务身份、因果关系、执行状态、按 `run_id` 关联的真实时间线、阶段产物引用和验收边界。它只消费 RuntimeStore 已登记事实，不写状态，也不把终态运行误当成人工验收；`public-safe` 会匿名化执行标识并移除产物正文。

## 验收

- 248 个 Python 用例通过。
- 87 个 Workbench 用例通过。
- 本机 Codex app-server 只读探测返回真实 thread/turn 回执。
- 私人 LongTask 浏览器完成 Codex 与自动路由绑定，并启动第一项有界任务。
- Codex 最终消息探测只把 `phase=final` 的内容登记为任务产物，过程性消息不进入交付结果。
- 项目归属验收创建真实 Codex 工作树任务，读取到非空 `projectId`，最终消息回写后 LongTask 进入 `REVIEW`。
